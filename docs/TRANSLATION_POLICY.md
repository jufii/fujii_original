# 日本語翻訳記事への変更（2026-10-30）

個別記事を許諾済み原記事の日本語訳として扱うモードを追加した。原題・媒体・著者・公開日時・原文URLを表示する。要約モードと翻訳モードを区別し、RSS概要しかない旧草稿を全文訳へ自動変更しない。

事実の独自取材を要求する代わりに、原文の意味・発言・確度を忠実に訳したかを人が確認する。原文の報道はreportedのまま扱える。AIが翻訳許諾を判断しない。公開にはsource-policyでlicensed_fulltextと商用許諾の証拠を人間が登録する必要がある。原文全文は公開JSONへ含めない。

出典表示や免責文だけで、翻訳・再掲載の許諾や掲載側の責任移転が成立するものではない。原媒体の報道内容と、THE TOUCHLINEの翻訳・掲載に関する役割を区別して表示する。

現存の2件はRSS概要による要約草稿であり、日本語訳記事に偽装せずneeds_reviewを維持する。全文訳を実際に作るには利用許諾のある原文が必要。
