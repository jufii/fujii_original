# THE TOUCHLINE — Daily News Automation

毎日05:30（Asia/Tokyo）に、THE TOUCHLINEのニュース生成ワークフローを実行してください。

1. リポジトリの `config/sources.yaml` を読み込む。
2. 許可されたニュースソースから過去24時間の新着情報を取得する。
3. 既存DB・記事履歴を確認し、重複ニュースを除外・統合する。
4. 欧州5大リーグのクラブごとに分類する。
5. ニュースの重要度と信頼性を判定する。
6. 日本語のチーム別朝刊と重要ニュース個別記事を作成する。
7. すべての記事に確認可能な出典URLを付与する。
8. 未確認情報や利用権限に問題のある記事を公開保留にする。
9. 記事を所定のJSONスキーマで `data/generated/YYYY-MM-DD/` に保存する。
10. Pythonの検証スクリプトとテストを実行する。
11. 公開条件を満たした記事だけを公開用データへ反映する。
12. 認可されたGitHub連携を通じて変更を保存し、公開ワークフローを起動する。
13. 処理件数、作成記事、保留記事、エラーを報告する。

OpenAI APIは使用しない。ニュース記事の全文を無断翻訳・転載せず、確認可能な事実に基づく独自の日本語記事を作成する。失敗時に公開済み記事を削除・上書きしない。
